# FRAME — Cinematic Video Editor Portfolio

A modern editorial portfolio starter for a video editor and colorist, built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

- Replace placeholder imagery and demo project titles with the editor's actual work.
- Update contact details in `app/page.tsx`.
- Add final video URLs to the project data.

The contact form is a front-end demo until connected to a form service or API route.
